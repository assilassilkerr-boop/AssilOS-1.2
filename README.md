# AssilOS 1.2
AssilOS 1.2 is 16-bit OS that based on AtieDOS.

## License

## Features
- Stra: an brainfuck interpreter
- changing prompt: you can actaully customize prompt 
- write: write text

## Getting started
AssilOS 1.2 is written in Assembly, you need:
- linux distros
- NASM Assembler
- dd
- QEMU (recommanded), DOSBox-X, VirtualBox, VMware, bochs
- CSM enable

## Avilable commands
- stra
- about
- chset
- clear
- echo
- help
- pause
- prompt
- restart
- shutdown
- write
